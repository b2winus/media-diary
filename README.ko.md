# Media Diary

[English](README.md)

본 영화·드라마·애니, 읽은 웹툰·만화, 들은 앨범을 옵시디언에 일기처럼 모아 두는 플러그인입니다. 제목으로 검색해 고르면 포스터와 출연진, 상세 정보가 담긴 노트를 만들고, 바로 별점(5점 만점, 0.5 단위)과 한줄평을 남길 수 있습니다.

한국 콘텐츠를 중심으로 만들었습니다. 한글 제목, 방송사, 국내 OTT, K-pop 앨범 형태가 자연스럽게 들어오고, 영미권 콘텐츠도 똑같이 쓸 수 있습니다.

## 기능

- **검색 창 하나로 여섯 가지 유형:** 영화·드라마(TMDB), 애니·웹툰·만화(AniList), 앨범(Apple Music)
- **앨범은 앨범 이름, 노래 제목, 가수 이름으로 찾기:** 한글과 영어 모두 됩니다. 노래 제목으로 찾으면 결과에 그 노래(♪ Holssi)가 표시되고, 그 노래가 실린 앨범으로 노트를 만듭니다.
- **제목 3종 저장:** 한글 제목, 영문 제목, 원제를 모두 저장하고 `aliases`에도 넣어 어느 이름으로든 노트를 찾을 수 있습니다.
- **한국 작품 우선:** 한글로 검색하면 한국 작품이 맨 위에 나옵니다.
- **K-콘텐츠에 필요한 정보:** 방송사(tvN, JTBC…), 국내 OTT(넷플릭스, 티빙…), 한국 시청등급, 웹툰 연재 플랫폼과 연재 상태, 앨범 형태(정규, 미니, 싱글, OST)
- **별점 5점 만점 0.5 단위** (노트에는 ★★★★½로 표시), 상태(봤음·읽는중·들음 등), 한줄평, 다시 볼 때마다 쌓이는 감상 날짜 기록(`watched_dates`)
- **명대사·가사·메모:** 기억하고 싶은 문장과 자유 메모를 노트의 각 섹션에 모아 둡니다.
- **고칠 수 있는 템플릿 3종** (영상·만화·음악). 변수가 모두 빈 줄은 빠지므로 영화 노트에 빈 '방송사' 줄이 남지 않습니다.
- **기존 노트 채우기:** 이미 있는 노트에 작품 정보만 더합니다. 별점과 감상은 그대로 둡니다.
- 한국어·영어 화면

## 시작하기

1. 커뮤니티 플러그인에서 Media Diary를 설치하고 켭니다.
2. 영화·드라마를 쓰려면 TMDB 키를 무료로 받습니다. [themoviedb.org](https://www.themoviedb.org/)에 가입한 뒤 [설정 → API](https://www.themoviedb.org/settings/api)에서 **API 키**나 **API 읽기 액세스 토큰**을 복사해 플러그인 설정에 넣고 **연결 확인**을 누르세요. 웹툰·만화·애니·앨범은 키 없이 됩니다.
3. 왼쪽 리본의 클래퍼보드 아이콘을 누르거나 **검색해서 미디어 다이어리에 추가** 명령을 실행합니다.

## 명령

| 명령 | 하는 일 |
| --- | --- |
| 검색해서 미디어 다이어리에 추가 | 유형을 고르고 검색해 새 노트를 만듭니다. |
| 현재 노트에 별점·감상 남기기 | 별점, 상태, 한줄평 창을 엽니다. |
| 현재 노트에 문구·메모 추가 | 문구·가사·메모만 남기는 작은 창을 엽니다. |
| 현재 노트 프런트매터에 작품 정보 채우기 | 지금 노트에 작품 정보를 더합니다. 별점·상태·한줄평은 그대로 둡니다. |

## 별점 창

- **별점:** 별을 누르세요(별의 왼쪽 절반은 반 개). ← → 로 0.5씩 조절하고, 0은 지우기, 숫자 1~5는 별 개수입니다.
- **한줄평**, **상태**, **날짜**(감상 날짜 기록에 추가)
- **남기고 싶은 문구:** 명대사, 기억하고 싶은 문장, 가사 한 구절. 출처(누가 한 말인지, 몇 화, 곡 제목)를 함께 적을 수 있고, 노트의 '명대사·문구' 섹션(앨범은 '가사·문구')에 인용 콜아웃으로 들어갑니다.
- **메모:** 그 밖에 남기고 싶은 것. 날짜와 함께 '메모' 섹션에 저장합니다.

Ctrl/Cmd + Enter로 저장합니다. 창을 다시 열어 문구를 더 넣을 수 있고, 먼저 넣은 문구는 그대로 남습니다.

별점은 두 가지로 저장됩니다. 한눈에 보이는 별(★★★★½)과, Bases나 Dataview에서 정렬할 때 쓰는 숫자입니다.

```yaml
status: 봤음
my_rating: 4.5
stars: ★★★★½
one_liner: "조용하고 따뜻하게 무너뜨리는 드라마"
watched_dates: ["2026-10-23"]
```

```markdown
## 명대사·문구

> [!quote] 주인공 · 3화 · 2026-10-27
> 나는 좋은 사람이 아니지만, 되고 싶어.
```

## 데이터 출처

- 영화·드라마: [TMDB](https://www.themoviedb.org/). *이 플러그인은 TMDB API를 사용하지만 TMDB의 보증이나 인증을 받지 않았습니다.*
- 애니·웹툰·만화: [AniList](https://anilist.co/)
- 앨범: Apple iTunes Search API. 기본으로 미국 스토어에서 찾고, 설정에서 일본·영국·캐나다·호주 스토어로 바꿀 수 있습니다. 한국 스토어는 음악을 팔지 않아 쓸 수 없습니다. 한국 가수와 노래도 다른 스토어에서 잘 찾아지지만, 제목이 영문이나 로마자로 표기되는 경우가 많습니다.

검색어만 위 서비스로 보냅니다. API 키는 보관소의 플러그인 설정에만 저장됩니다.
